# Project instructions

- When Alex says to push Datameter to GitHub, include the release step: update the app and installer
  versions, build the supported setup files, update the GitHub release notes/assets, and publish a
  new release after the changes are on `main`. Do not stop after pushing a source branch.
- Keep release installers for x64, ARM64 and x86 in sync with the app version and keep the stable
  `DatameterSetup-<arch>.exe` asset names so the README's latest-release download links continue to
  work.
